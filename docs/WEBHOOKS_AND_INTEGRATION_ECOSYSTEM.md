# FocusBoard Webhooks & Integration Ecosystem

FocusBoard delivers real-time event notifications to external partner services via signed HTTP POST webhooks and provides verified third-party connectors.

---

## 1. Cryptographic HMAC-SHA256 Webhook Signatures

All outbound webhooks generated by FocusBoard include an `X-FocusBoard-Signature` (or standard `FocusBoard-Signature`) header:

```http
FocusBoard-Signature: t=1795338491,v1=5f2d3a9...0b1
```

### Verification Algorithm:
1. Extract the timestamp `t` and signature `v1` from the header.
2. Prepare the signature base string:
   ```
   t=<timestamp>.<raw_json_payload>
   ```
3. Compute the HMAC-SHA256 hash using your secret signing key:
   ```python
   import hmac
   import hashlib

   expected_hash = hmac.new(
       secret_key.encode("utf-8"),
       signature_base.encode("utf-8"),
       hashlib.sha256
   ).hexdigest()
   ```
4. Perform constant-time comparison to prevent timing attacks:
   ```python
   hmac.compare_digest(expected_hash, v1)
   ```
5. Reject requests older than 300 seconds (5 minutes) to protect against replay attacks.

## 2. Marketplace App Permission Consent

When users install an application from the FocusBoard Marketplace:
1. **Explicit Scope Consent**: The user is presented with the exact list of scopes requested by the developer (e.g., `tasks:read`, `tasks:write`, `webhooks:read`).
2. **Audit Logging**: The installation record captures the user who authorized the connection, the granted scopes snapshot, and the installation timestamp.
3. **Revocation**: Removing the app revokes active tokens and webhook subscriptions.

## 3. Supported Integrations Catalog

- **Google Calendar**: Bi-directional calendar sync, sprint deadline blocking, and automated event generation.
- **Slack**: Channel notifications, SLA warnings, and standup digests.
- **GitHub**: Commit, pull request, and release synchronization with task cards.
- **Linear / Jira**: Two-way issue tracker synchronization.
- **Generic Webhook**: User-configured endpoints for arbitrary event consumption.
